## Datasets
This folder contains the raw datasets downloaded from Kaggle and used for building the Netflix and Healthcare analytics projects. These datasets serve as the foundation for SQL analysis, data cleaning in Excel, and dashboard development in Power BI.
The data in this folder represents the original, unmodified source files before transformation.

## Netflix Titles Dataset

File: Netflix_Analysis/netflix_titles(raw).csv,
Source: Kaggle

## Description
This dataset contains detailed information about movies and TV shows available on Netflix, including:

Title:-
1. Content Type (Movie / TV Show)
2. Director & Cast
3. Country
4. Release Year
5. Rating
6. Duration
7. Date Added
8. Genre (Listed In)
9. Description

Purpose in Project (Used to Analyze):-
1. Content distribution by genre
2. Top producing countries
3. Ratings breakdown
4. Content growth over time
5. Movies vs TV Show comparison

This dataset forms the base for the Netflix Content Analysis Dashboard.

## Healthcare Patient Flow Dataset

File: Healthcare_Analysis/healthcare_analytics_patient_flow_data_raw_data.csv,
Source: Kaggle

## Description
This dataset contains hospital patient visit records, including:

Title:-
1. Patient ID
2. Admission Date & Time
3. Department
4. Admission Status
5. Wait Time
6. Satisfaction Score
7. Gender
8. Age & Age Group
9. Race

Purpose in Project (Used to Analyze):-
1. Patient visit trends
2. Admission rates
3. Department performance
4. Wait time analysis
5. Satisfaction trends

This dataset supports:-
1. SQL-based healthcare analytics
2. Data cleaning in Excel
3. Healthcare Patient Flow Dashboard in Power BI

## How These Datasets Are Used:-
1. Raw data stored in this folder
2. Cleaned & transformed in the Excel folder
3. Analyzed using SQL (Healthcare project)
4. Visualized in Power BI dashboards
