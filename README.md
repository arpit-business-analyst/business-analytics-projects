## Kaggle Projects – End-to-End Data Analytics
This branch contains complete data analytics projects built using datasets sourced from Kaggle.

Each project follows a structured workflow including:
1. Raw data collection
2. Data cleaning & transformation
3. SQL-based analysis
4. Dashboard development
5. Insight generation
The goal of this branch is to demonstrate practical analytics skills using real-world datasets.

## Netflix Content Analysis
## Overview
This project analyzes Netflix movies and TV shows to understand content distribution, genre trends, country contribution, rating distribution, and growth over time.

## Project Components
## Datasets
1. Raw dataset downloaded from Kaggle
2. Contains title-level information including genre, country, rating, duration, and release year

## Excel
1. Cleaned and structured dataset
2. Extracted year fields
3. Standardized formats
4 .Prepared data for visualization

## Dashboards
1. Power BI dashboard
2. Interactive filters for rating, year, and country
3. KPI cards for total movies, TV shows, and titles

## Key Analysis Performed
1. Movie vs TV show distribution
2. Top genres on Netflix
3. Top countries by content count
4. Rating distribution
5. Titles added over time

## Healthcare Patient Flow & Admission Analysis
## Overview
This project analyzes hospital patient flow, admissions, wait times, department performance, and satisfaction trends.

## Project Components
## Datasets
1. Raw healthcare patient flow dataset from Kaggle
2. Includes admission details, department data, patient demographics, and satisfaction scores

## Excel
1. Data cleaning and validation
2. Derived columns (year, month, time-based fields)
3. Pivot tables for exploratory analysis

## SQL
1. MySQL queries for:
2. Admission rate calculation
3. Department-wise performance
4. Wait time analysis
5. Trend-based aggregations

## Dashboards
1. Power BI dashboard
2. KPI cards (Total Visits, Admissions, Avg Satisfaction, Avg Wait Time)
3. Department & hourly trend analysis
4. Admission vs Non-admission comparison

## Key Analysis Performed
1. Admission rate by department
2. Wait time range analysis
3. Satisfaction trend analysis
4. Hourly visit trends
5. Patient distribution analysis

This branch is structured to reflect a real-world analytics pipeline.

The focus is on:
1. Structured folder organization
2. Clean data workflow
3. Practical SQL implementation
4. Business-oriented dashboard insights
